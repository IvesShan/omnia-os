# 聊天上下文增强功能

## 📊 功能概述

本次更新大幅增强了聊天系统的上下文处理能力，包括：

1. **上下文窗口扩大 4 倍**: 50 → 200 条消息
2. **智能对话摘要压缩**: 自动压缩旧消息，保留关键信息
3. **Token 节省**: 预计节省 30-50% token 使用

## 🚀 新增功能

### 1. 扩大的上下文窗口

**改进前**: 只发送最近 50 条消息作为上下文
**改进后**: 发送最近 200 条消息作为上下文

**优势**:
- 更好的长对话理解
- 更连贯的上下文关联
- 充分利用大模型的长上下文能力

### 2. 自动摘要压缩

**触发条件**: 当对话消息超过 50 条时自动触发

**压缩策略**:
- 压缩前 30 条消息（50 - 20 = 30）
- 保留最近 20 条原始消息
- 使用 LLM 生成高质量摘要

**压缩效果**:
- 保留所有重要信息、决策、结论
- 保留技术细节、代码片段、配置信息
- 保留待办事项和未完成的任务
- 保持时间顺序

### 3. 手动摘要生成

**功能**: 用户可以手动生成对话摘要

**使用场景**:
- 想要查看对话总结
- 需要提取关键信息
- 准备分享对话内容

## 🔧 配置参数

### 前端配置 (web/summary.js)

```javascript
const SUMMARY_CONFIG = {
  COMPRESS_THRESHOLD: 50,  // 触发压缩的消息数量阈值
  KEEP_RECENT: 20,         // 保留最近的消息数量
  API_ENDPOINT: '/api/chat/summarize/auto',
  ENABLED: true,           // 是否启用自动压缩
};
```

### 后端配置 (src/omnia/routers/summary.py)

```python
SUMMARY_SYSTEM_PROMPT = """..."""  # 摘要生成的系统提示
```

## 📡 API 接口

### 1. 手动生成摘要

**端点**: `POST /api/chat/summarize`

**请求体**:
```json
{
  "messages": [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！有什么可以帮助你的吗？"}
  ],
  "max_length": 500
}
```

**响应**:
```json
{
  "ok": true,
  "summary": "用户打招呼，助手回应并询问帮助需求。",
  "token_saved": 15
}
```

### 2. 自动压缩

**端点**: `POST /api/chat/summarize/auto`

**请求体**:
```json
{
  "messages": [
    {"role": "user", "content": "消息1"},
    {"role": "assistant", "content": "回复1"},
    // ... 更多消息
  ]
}
```

**响应**:
```json
{
  "ok": true,
  "messages": [
    {"role": "system", "content": "【对话历史摘要】\n...\n\n【以下是最近的对话】"},
    // 最近的 20 条消息
  ],
  "summary": "对话摘要内容...",
  "token_saved": 1500
}
```

## 🔍 工作原理

### 前端流程

1. 用户发送消息
2. 构建最近 200 条消息作为原始历史
3. 调用 `buildCompressedHistory(rawHistory)`
4. 如果消息数 ≤ 50，直接返回原始历史
5. 如果消息数 > 50，调用后端自动压缩 API
6. 返回压缩后的消息列表
7. 发送到后端进行对话

### 后端流程

1. 接收压缩请求
2. 分割消息：旧消息（需要压缩）+ 新消息（保留原始）
3. 调用 LLM 生成旧消息的摘要
4. 构建压缩后的消息列表：摘要 + 最近消息
5. 返回压缩后的消息和节省的 token 数

## 🛠️ 故障排除

### 问题：压缩未触发

**可能原因**:
- 消息数未超过 50 条阈值
- 自动压缩功能被禁用
- 后端 API 调用失败

**解决方法**:
1. 检查 `SUMMARY_CONFIG.ENABLED` 是否为 `true`
2. 查看浏览器控制台是否有错误
3. 检查后端日志

### 问题：压缩后消息丢失

**可能原因**:
- 摘要生成失败
- 压缩逻辑错误

**解决方法**:
1. 检查后端日志
2. 手动调用摘要 API 测试
3. 确认 LLM 服务正常
