## 📊 一、缓动曲线（Easing Curves）

### 1.1 常用缓动类型

| 缓动类型 | CSS函数 | 适用场景 |
|----------|---------|----------|
| **标准缓动** | `ease` | 通用动画，从静止开始减速 |
| **缓入** | `ease-in` | 元素退出画面（如淡出） |
| **缓出** | `ease-out` | 元素进入画面（如淡入） |
| **缓入缓出** | `ease-in-out` | 元素在画面内移动 |
| **线性** | `linear` | 颜色变化、进度条 |

### 1.2 Material Design 3 标准缓动

```
标准：cubic-bezier(0.2, 0, 0, 1)
强调：cubic-bezier(0.2, 0, 0, 1)
减速：cubic-bezier(0, 0, 0, 1)
加速：cubic-bezier(0.3, 0, 1, 1)
```

### 1.3 Apple HIG 推荐

```
标准：cubic-bezier(0.25, 0.1, 0.25, 1)
弹性：spring(response: 0.55, dampingFraction: 0.825)
```

## ⏱️ 二、动画时长（Duration）

### 2.1 时长标准

| 元素类型 | 推荐时长 | 说明 |
|----------|----------|------|
| **微交互** | 100-200ms | 按钮点击、开关切换 |
| **小元素** | 200-300ms | 图标、标签、小卡片 |
| **中等元素** | 300-400ms | 对话框、菜单、卡片 |
| **大元素** | 400-500ms | 页面转场、大面积动画 |
| **复杂动画** | 500-700ms | 多步骤、叙事性动画 |

### 2.2 Material Design 3 时长

| 类型 | 时长 |
|------|------|
| 短 | 150ms |
| 中 | 300ms |
| 长 | 500ms |
| 超长 | 700ms |

### 2.3 关键原则

- **100ms以下**：用户感觉"即时"
- **100-300ms**：用户感觉"流畅"
- **300-500ms**：用户感觉"有意识"
- **500ms以上**：用户可能感到"等待"

## 🎯 三、动画节奏原则

### 3.1 12条动画法则（迪士尼）

| 法则 | 说明 | 应用 |
|------|------|------|
| **挤压与拉伸** | 物体运动时的形变 | 强调物体的重量感和弹性 |
| **预备动作** | 动作前的蓄力 | 让观众预期即将到来的动作 |
| **舞台呈现** | 引导观众注意力 | 突出关键元素 |
| **连续动作与姿态** | 动作的流畅衔接 | 保持视觉连贯性 |
| **跟随与重叠** | 次要元素的延迟 | 增加真实感 |
| **慢入慢出** | 缓动曲线 | 避免机械感 |
| **弧形运动** | 自然的运动轨迹 | 避免直线运动 |
| **次要动作** | 辅助性动作 | 丰富画面层次 |
| **时间控制** | 动作节奏 | 表达情感和意图 |
| **夸张** | 适度夸张 | 强化视觉效果 |
| **扎实绘画** | 几何形状基础 | 保持视觉一致性 |
| **吸引力** | 视觉魅力 | 吸引观众注意力 |

### 3.2 视频制作节奏

```
开场（Hook）：快节奏，0.5-1秒/元素
主体内容：中等节奏，1-2秒/要点
转场：0.3-0.5秒
结尾：慢节奏，2-3秒/元素
```

## 🎨 四、视觉规范

### 4.1 颜色使用

| 类型 | 建议 |
|------|------|
| **主色** | 1-2个，用于关键元素 |
| **辅助色** | 2-3个，用于次要元素 |
| **中性色** | 黑白灰，用于背景和文字 |
| **强调色** | 1个，用于CTA和重点 |

### 4.2 字体层级

```
标题：24-32px，粗体
副标题：18-24px，半粗体
正文：14-16px，常规
注释：12px，常规或细体
```

### 4.3 留白原则

```
元素间距：8px的倍数（8, 16, 24, 32, 48）
边距：16-24px
呼吸空间：元素周围至少8px
```

## 🎬 五、视频制作规范

### 5.1 画面构图

| 原则 | 说明 |
|------|------|
| **三分法** | 将画面分为3×3网格，关键元素放在交叉点 |
| **黄金比例** | 1:1.618，适用于布局比例 |
| **视觉层次** | 大小、颜色、位置区分主次 |
| **对齐** | 保持元素对齐，增强秩序感 |

### 5.2 文字动画

| 类型 | 时长 | 缓动 |
|------|------|------|
| **淡入** | 300ms | ease-out |
| **打字机** | 50ms/字 | linear |
| **逐字显示** | 100ms/字 | ease-out |
| **弹入** | 400ms | cubic-bezier(0.68, -0.55, 0.27, 1.55) |

### 5.3 转场效果

| 类型 | 时长 | 适用场景 |
|------|------|----------|
| **淡入淡出** | 400-600ms | 场景切换 |
| **滑动** | 300-400ms | 同级内容切换 |
| **缩放** | 300-500ms | 强调、聚焦 |
| **旋转** | 400-600ms | 创意、活泼风格 |
| **遮罩** | 500-700ms | 高级转场 |

## 📱 六、响应式动画

### 6.1 性能优化

| 原则 | 说明 |
|------|------|
| **GPU加速** | 使用transform和opacity |
| **避免重排** | 不要动画化width、height、margin |
| **will-change** | 提前告知浏览器动画元素 |
| **requestAnimationFrame** | 使用RAF而非setTimeout |

### 6.2 降级策略

```
低性能设备：减少动画元素、降低复杂度
无障碍：尊重prefers-reduced-motion设置
网络慢：优先加载关键动画，延迟加载装饰性动画
```

## 🛠️ 七、HypersNes应用指南

### 7.1 推荐设置

```javascript
// 标准动画
duration: 300,
easing: 'cubic-bezier(0.2, 0, 0, 1)'

// 进入动画
duration: 400,
easing: 'cubic-bezier(0, 0, 0, 1)'

// 退出动画
duration: 200,
easing: 'cubic-bezier(0.3, 0, 1, 1)'

// 弹性动画
duration: 500,
easing: 'cubic-bezier(0.68, -0.55, 0.27, 1.55)'
```

### 7.2 字幕动画模板

```javascript
// 淡入效果
{
  opacity: { from: 0, to: 1 },
  duration: 300,
  easing: 'ease-out'
}

// 弹入效果
{
  scale: { from: 0.8, to: 1 },
  opacity: { from: 0, to: 1 },
  duration: 400,
  easing: 'cubic-bezier(0.68, -0.55, 0.27, 1.55)'
}

// 滑入效果
{
  translateY: { from: 20, to: 0 },
  opacity: { from: 0, to: 1 },
  duration: 350,
  easing: 'cubic-bezier(0.2, 0, 0, 1)'
}
```

### 7.3 视频节奏模板

```
抖音短视频（15-60秒）：
├── 开场Hook：0-3秒，快节奏，吸引注意力
├── 核心内容：3-45秒，中等节奏，清晰传达
├── CTA：最后3-5秒，慢节奏，引导行动
└── 转场：0.3-0.5秒，简洁流畅
```

## ✅ 快速检查清单

### 动画质量检查
- [ ] 缓动曲线是否自然？
- [ ] 时长是否合适（不过快也不过慢）？
- [ ] 动画是否有明确的目的？
- [ ] 是否遵循视觉层次？
- [ ] 是否考虑了性能？

- [ ] 节奏是否舒适？
