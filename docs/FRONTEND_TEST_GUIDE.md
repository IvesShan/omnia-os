
## 🔍 测试检查点

### API 端点测试

```bash
# 健康检查
curl http://localhost:5001/health

# 模型状态
curl http://localhost:5001/api/model/status

# 模型切换
curl -X POST http://localhost:5001/api/model/mode \
  -H "Content-Type: application/json" \
  -d '{"mode": "local_only"}'

# 聊天测试
curl -X POST http://localhost:5001/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'
```

### 静态资源测试

```bash
# CSS
curl -I http://localhost:5001/static/css/app.css

# JavaScript
curl -I http://localhost:5001/static/js/app.js
curl -I http://localhost:5001/static/js/model-switcher.js
```

## 🐛 常见问题

### 1. 前端无法访问

**检查项：**
- [ ] 后端服务是否启动
- [ ] 端口 5001 是否被占用
- [ ] 防火墙是否阻止访问

**解决方案：**
```bash
# 检查服务状态
curl http://localhost:5001/health

# 检查端口占用
lsof -i :5001
```

### 2. 模型切换失败

**检查项：**
- [ ] llama.cpp 是否启动（本地模式）
- [ ] API 密钥是否配置（云端模式）
- [ ] 网络连接是否正常

**解决方案：**
```bash
# 启动本地模型
bash scripts/llm_128k_context.sh

# 检查模型状态
curl http://localhost:5001/api/model/health
```

### 3. 聊天无响应

**检查项：**
- [ ] 模型是否在线
- [ ] API 端点是否正常
- [ ] 请求超时设置

**解决方案：**
```bash
# 测试聊天 API
curl -X POST http://localhost:5001/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "测试"}'
```
