# 🧪 Omnia 模型切换 UI 测试指南

## 📍 测试访问

**测试页面**: http://localhost:8888/test_frontend_ui.html

**启动命令**:
```bash
bash start_ui_test.sh
```

---

## 🎯 测试功能

### 1. 实时状态监控
- ✅ 后端服务状态
- ✅ 本地模型状态（llama.cpp）
- ✅ 云端模型状态（Moonshot API）
- ✅ 当前运行模式
- 🔄 自动刷新（每 5 秒）

### 2. 模式切换测试
- 🖥️ **本地 GPU 模式** - 使用本地 Gemma 4 128K
- ☁️ **云端模式** - 使用 Kimi/Qianfan API
- 🤖 **智能模式** - 自动选择最优模型

### 3. 聊天功能测试
- 💬 发送消息测试
- 📊 响应时间统计
- ✅ 模型响应验证

### 4. 自动化测试
- 🔄 一键运行所有测试
- 📋 测试结果实时显示
- 📊 历史记录保留（最近 10 条）

## 🚀 快速开始

### 方式 1: 自动启动（推荐）
```bash
cd /home/shan/omnia-os
bash start_ui_test.sh
```

### 方式 2: 手动启动
```bash
# 1. 启动后端
python3 src/omnia/web_server.py

# 2. 启动测试服务器
python3 -m http.server 8888

# 3. 打开浏览器
# http://localhost:8888/test_frontend_ui.html
```

## 📝 测试步骤

### 步骤 1: 检查状态
打开页面后，等待状态自动刷新：
- ✅ 后端服务应显示"在线"
- ✅ 云端模型应显示"在线"
- ⚠️ 本地模型需要先启动 llama.cpp

### 步骤 2: 启动本地模型（可选）
```bash
bash scripts/llm_128k_context.sh
```

### 步骤 3: 运行自动化测试
点击页面上的 **"运行所有测试"** 按钮

### 步骤 4: 手动测试
1. 点击不同模式按钮切换
2. 在聊天框输入消息测试
3. 观察状态变化和响应

## 🎨 UI 功能说明

### 状态指示灯
- 🟢 **绿色** - 在线/可用
- 🔴 **红色** - 离线/不可用
- 🟡 **黄色** - 检查中/加载中

### 测试结果
- ✅ **绿色** - 测试通过
- ❌ **红色** - 测试失败
- ℹ️ **蓝色** - 信息提示

## 📊 API 端点

测试页面会调用以下 API：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/model/status` | GET | 获取模型状态 |
| `/api/model/mode` | POST | 切换模式 |
| `/api/chat` | POST | 发送聊天消息 |

## 🔧 故障排查

### 问题 1: 后端服务离线
```bash
# 检查后端是否运行
pgrep -f "omnia_backend.py"

# 重启后端
python3 src/omnia/web_server.py
```

### 问题 2: 本地模型离线
```bash
# 启动 llama.cpp
bash scripts/llm_128k_context.sh

# 检查是否运行
curl http://localhost:8080/health
```

### 问题 3: CORS 错误
后端已配置 CORS，如果仍有问题：
```bash
# 检查后端日志
tail -f /tmp/omnia_backend.log
```
