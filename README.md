## 📦 安装

### 方式一：下载安装包（推荐）

从 [Releases](https://github.com/542575819/omnia-os/releases) 下载对应平台的安装包：

- **Windows**: `omnia-windows-amd64.zip`
- **macOS**: `omnia-macos-amd64.tar.gz`
- **Linux**: `omnia-linux-amd64.tar.gz`

### 方式二：从源码运行

```bash
git clone https://github.com/542575819/omnia-os.git
cd omnia-os
pip install -r requirements.txt
python backend/standalone_main.py
```
