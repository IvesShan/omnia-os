# Drone Course Developer Skill

## 概述

本 Skill 封装了无人机维修培训课程开发的最佳实践，包括课程设计规范、讲义编写技巧、外部信息验证原则等。

## 适用场景

- 开发无人机维修培训课程
- 编写培训讲义和课件
- 设计课程大纲和教学计划
- 确保内容真实性和准确性

## 核心能力

### 1. 课程设计规范

#### 教学大纲四要素
1. **课程目标设定** - 遵循 SMART 原则
   - S (Specific) - 具体明确
   - M (Measurable) - 可衡量
   - A (Achievable) - 可实现
   - R (Relevant) - 相关性
   - T (Time-bound) - 时间限制

2. **课程内容组织** - 自浅入深，分层模块化
3. **教学方法** - 721法则
   - 70% 实操练习
   - 20% 同伴学习
   - 10% 理论讲授
4. **评价体系** - 过程评价 + 结果评价结合

#### 课程结构模板
```
25天课程结构示例：
├── 第一阶段：基础与法规（Day 01-05）
├── 第二阶段：核心系统（Day 06-10）
├── 第三阶段：实战专题（Day 11-15）
└── 第四阶段：商业运营（Day 16-25）
```

### 2. 讲义编写口语化技巧

#### 五大原则

1. **简化句子结构**
   - ❌ 书面语："本次培训活动旨在提高员工的专业技能..."
   - ✅ 口语化："这次培训就是为了提升大家的专业技能..."

2. **使用通俗易懂词汇**
   - 避免生僻术语
   - 用大白话解释专业概念

3. **增加互动感**
   - 使用"我们"、"大家"、"你"等称呼
   - 示例："大家有没有想过..."、"我们来看看..."

4. **适当使用语气词**
   - "其实啊..."、"简单来说..."
   - 让内容更生动自然

5. **段落简短**
   - 每段不超过3-4行
   - 便于阅读和理解

#### 讲义标准结构
```markdown

...
```

### 3. 外部信息验证原则

#### 数据使用规范
- ✅ 使用可验证的官方数据（大疆官网、政府法规）
- ✅ 无法验证的数据使用保守表述
- ✅ 定性描述优于定量数字
- ❌ 不编造具体数字
- ❌ 不引用无法验证的来源

#### 保守表述示例
```
❌ "全球保有量超过2000万台"
✅ "累计销量达数百万台，市场领先地位稳固"
✅ "占据全球消费级市场主导地位"
```

#### 信息来源优先级
1. 官方网站（dji.com）
2. 国内权威媒体（36氪等）
3. 百度搜索（国内可访问）
4. ❌ 国外网站（可能无法访问）

### 4. 物熵科技业务特色

#### 核心理念
- **真机实操，拒绝纸上谈兵**
- 小班教学
- 从基础到芯片级的完整技术链

#### 课程开发要点
1. **实操机型** - Mini/Air/Mavic 2 系列
2. **保留技术** - 字库读写、电池解锁扩容、云台标定
3. **排除内容** - 飞丢解锁（敏感）、芯片级搬板（过于专业）
4. **新增内容** - 无人机法规（实名登记、飞行许可等）

### 5. 课件设计标准

#### Apple Keynote 风格规范
- **背景**: #000000 (纯黑)
- **字体**: Inter
- **配色**:
  - 蓝色 #0a84ff (强调)
  - 绿色 #30d158 (实操机型)
  - 橙色 #ff9f0a (警告)
  - 红色 #ff453a (危险)
  - 紫色 #bf5af2 (专业)

#### 内容展示原则
- 实操机型 = 绿色边框
- 介绍机型 = 灰色边框
- 使用 SVG 代码绘制图示（避免外部图片问题）
- 大留白设计（80px-100px padding）

## 使用示例

### 示例1：编写课程大纲

用户：帮我设计一个无人机电机维修课程

应用本 Skill：
1. 确定课程时长（建议4小时）
2. 按721法则分配时间
   - 理论讲解：24分钟（10%）
   - 同伴讨论：48分钟（20%）
   - 实操练习：168分钟（70%）
3. 设计内容模块
   - 电机结构认知
   - 正反转识别
   - 拆卸与更换
   - 测试与调试
4. 编写讲义（使用口语化技巧）
5. 设计实操练习和作业

### 示例2：验证数据真实性

用户：课程中需要引用大疆市场份额数据

应用本 Skill：
1. 尝试访问大疆官网获取官方信息
2. 搜索国内权威媒体报道
3. 无法找到确切数字时：
   - 使用定性描述："占据全球消费级市场主导地位"
   - 避免使用："70%市场份额"（除非有明确来源）

### 示例3：优化讲义表达

原文：
"本次培训课程的教学目标是使学员掌握无人机的基本维修技能。"

优化后（口语化）：
"咱们这次培训的目标很简单——让你学会修无人机！从最基础的拆装开始，一步步变成维修高手。"

## 注意事项

1. **数据真实性第一** - 不确定的内容标注"待确认"
2. **口语化不等于随意** - 保持专业性的同时让表达更自然
3. **实操为王** - 任何理论都要有对应的动手环节
4. **持续迭代** - 根据学员反馈不断优化课程内容
