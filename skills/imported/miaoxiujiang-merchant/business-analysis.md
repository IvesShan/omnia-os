## 二、业务流程

### 标准维修流程

```
客户咨询 → 下单登记 → 收件确认 → 外观检测 → 详细检测 → 
生成报价 → 客户确认 → 维修执行 → 质量检验 → 发货/通知取件 → 
客户确认收货 → 财务结算 → 发票开具 → 售后跟进
```

### 状态流转

1. **pending** - 待接单
2. **accepted** - 已接单/待收件
3. **received** - 已收件待检测
4. **inspected** - 已检测待报价
5. **quoted** - 已报价待确认
6. **confirmed** - 已确认待维修
7. **repairing** - 维修中
8. **repaired** - 已维修待发货
9. **shipped** - 已发货/待取件
10. **delivered** - 已送达/已取件
11. **completed** - 已完成

## 三、商家后台功能需求

### 核心模块

#### 1. 仪表盘 (Dashboard)
- 今日统计：新订单数、待检测数、维修中数
- 收入统计：今日收入、本周收入、本月收入
- 待办事项：待接单、待检测、待报价、待发货
- 快捷入口：接单、检测、报价、发货

#### 2. 订单管理 (Orders)
- 订单列表（按状态筛选）
- 订单详情查看
- 订单状态流转操作
- 搜索功能（案例号、客户名、手机号）

#### 3. 检测管理 (Inspection)
- 创建检测报告
- 填写外观检测结果
- 上传检测照片
- 生成维修报价单

#### 4. 报价管理 (Quotation)
- 维修项目添加（配件+人工）
- 多方案报价（方案A/B）
- 生成PDF报价单
- 发送给客户

#### 5. 库存管理 (Inventory)
- 配件库存查看
- 配件消耗记录
- 库存预警
- 配件编码管理

#### 6. 物流管理 (Logistics)
- 收件确认（输入快递单号）
- 发货登记（选择快递、输入单号）
- 物流跟踪

#### 7. 财务管理 (Finance)
- 收入统计
- 成本核算
- 利润分析
- 发票管理

#### 8. 客户管理 (Customers)
- 客户列表
- 客户历史订单
- 客户标签

## 五、关键业务规则

1. **配件编码规则**：P-{机型代码}-{类别代码}-{序号}
   - 例：P-M3P-YT-DJZ-001 (Mini 3 Pro 云台电机)

2. **案例号生成规则**：CAS-年月日-随机4位
   - 例：CAS-20251019-EnOP

3. **订单号生成规则**：WR年月日时分秒
   - 例：WR20251019153809

4. **结算规则**：
   - 毛利率 = (实际成交 - 成本) / 实际成交
   - 目标利润率：12-15%

5. **物流规则**：
   - 客户寄件：到付
   - 商家发货：包邮（默认）或到付
