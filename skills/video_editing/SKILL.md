## Description

提供 AI 辅助的视频编辑能力，包括自动剪辑、字幕生成、特效添加、格式转换等后期处理功能。

## Capabilities

- auto-edit: 智能剪辑 - 根据内容自动裁剪、拼接
- subtitle: 字幕生成 - ASR 语音识别自动生成字幕
- effects: 特效添加 - 转场、滤镜、动画
- format: 格式转换 - 多格式支持 (MP4, WebM, MOV)
- compress: 视频压缩 - 智能压缩保持画质

## Triggers

当用户提到以下关键词时自动激活：
- 视频剪辑 / 视频编辑 / video editing
- 加字幕 / 字幕生成 / subtitle
- 视频压缩 / 视频转换 / format convert

## Usage

```
"帮我剪辑一下这个视频" → 激活此技能
"给视频加字幕" → 激活此技能
"把视频转成GIF" → 激活此技能
```
