## 四、口播脚本结构规范

### 黄金结构（60秒口播）

```
0-3秒：钩子（数字/冲突/悬念）← 决定2秒跳出率
3-15秒：痛点共鸣（"你是不是也遇到过..."）
15-45秒：干货输出（具体案例/数据/步骤）
45-55秒：变现钩子（自然引出OPC/工具/服务）
55-60秒：互动引导（"你觉得呢？评论区聊聊"）
```

### 变现钩子植入方式（不要硬广！）

| 变现目标 | 植入方式 | 示例 |
|---------|---------|------|
| OPC方案 | 分享创业故事时自然带出 | "我就是用OPC模式起步的，成本3万，3个月回本" |
| 维修工具 | 教程中展示工具使用 | "用这套工具，检测效率提升3倍"（不提购买） |
| 维修订单 | 展示维修案例时带出 | "上周一个客户Mini 3 Pro炸机..."（建立专业感） |
| 知识付费 | 分享干货后留钩子 | "完整的维修流程我放在主页了" |

**原则：80%干货 + 20%变现暗示。永远不要超过20%的变现内容。**

## 六、流量预测模型

### 预估公式

```
预估播放 = 基准播放 × 选题系数 × 标题系数 × 时间系数
```

**基准播放**：当前账号中位数播放 = **650**（随粉丝增长定期更新）

| 变量 | 条件 | 系数 |
|------|------|------|
| **选题** | 政策法规/新规 | ×70 |
| | 实用教程/操作指南 | ×60 |
| | 行业热点/大疆新闻 | ×10 |
| | 行业观点/OPC/创业 | ×3 |
| | 维修行业/市场分析 | ×1 |
| | 职业规划/鸡汤 | ×0.6 |

| **时间** | 14:00-17:00 | ×1.5 |

## 七、自学习校准机制

### 每次用户发布新视频后，执行以下步骤：

1. **收集数据**：用户提供实际播放量、点赞、评论、分享
2. **计算偏差**：`偏差 = (实际播放 - 预估播放) / 预估播放`
3. **调整系数**：
   - 如果偏差 > 50%：该选题/标题系数上调 20%
   - 如果偏差 < -50%：该选题/标题系数下调 20%
   - 如果偏差在 ±20% 以内：模型准确，不调整
4. **更新基准播放**：`新基准 = 近10条视频的中位数播放`
5. **记录到 data/predictions.json**

### 校准记录格式
```json
{
  "video_id": "2026-05-08-001",
  "title": "视频标题",
  "predicted": 3500,
  "actual": 8200,
  "deviation": "+134%",
  "adjustment": "行业观点系数 ×3 → ×3.6",
  "timestamp": "2026-05-08T18:00:00Z"
}
```

## 八、文案优化工作流

当用户发送文案草稿时，按以下流程处理：

### Step 1：选题分类
判断文案属于哪个选题类型，给出流量系数

### Step 2：标题优化
- 检查是否包含紧迫词、痛点、利益点
- 检查是否有 ? 或 ！
- 给出优化建议和2-3个备选标题

### Step 3：脚本结构检查
- 开头3秒是否有钩子？
- 是否有痛点共鸣？
- 干货是否具体（数字/案例/步骤）？
- 变现钩子是否自然植入（不超过20%）？
- 结尾是否有互动引导？

### Step 4：流量预估
根据公式计算预估播放区间

### Step 5：变现评估
- 这条视频能带来什么变现机会？
- OPC/工具/维修订单/知识付费，哪个最合适？
- 变现钩子怎么植入最自然？

### 输出格式
```
📊 文案分析报告

【选题类型】XXX | 流量系数 ×XX
【标题评分】X/10 — 原因
【优化标题】
  1. ...
  2. ...
  3. ...
【脚本评分】X/10
  ✅ 优点：...
  ⚠️ 改进：...
【流量预估】XX,XXX - XX,XXX 播放
```
