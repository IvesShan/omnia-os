# 抖音内容优化 Skill 使用指南

## 怎么用

### 1. 发文案给我优化
直接把你的口播文案发给我，我会：
- 分析选题类型，判断流量潜力
- 优化标题（紧迫词+痛点+利益+标点）
- 检查脚本结构（钩子→痛点→干货→变现→互动）
- 预估播放量区间
- 给出变现建议（OPC/工具/维修订单）

### 2. 发布后给我实际数据
视频发布后，把实际数据发给我：
```
播放：XXX | 点赞：XXX | 评论：XXX | 分享：XXX
```
我会用实际数据校准预测模型，让下次预测更准。

### 3. 问选题建议
直接问"下一条拍什么"，我会根据：
- 当前热点话题
- 你账号的数据规律
- 变现目标优先级
给出3-5个选题建议，按预估播放排序。
