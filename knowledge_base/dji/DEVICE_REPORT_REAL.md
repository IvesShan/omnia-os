## 🔧 技术细节

### 协议格式

```
字节 0: 头部 (0x55)
字节 1: 长度
字节 2: 保留 (0x00)
字节 3: 命令
字节 N: 数据 (可选)
字节 N+1: 校验和
```

### 型号代码位置

在心跳响应中，型号代码位于第 12-15 字节：
```
... 81 57 41 31 34 31 ...
      W  A  1  4  1
```
