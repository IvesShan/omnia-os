## 📱 系统说明

**chat.html** 是喵修匠的客户端AI对话界面，提供完整的无人机维修服务流程。

---

## 🚀 核心功能

| 功能模块 | 说明 |
|----------|------|
| **AI故障诊断** | 智能分析无人机故障，提供维修建议 |
| **在线下单** | 创建维修订单，支持图片/视频上传 |
| **订单跟踪** | 实时查看订单状态、维修进度 |
| **物流查询** | 快递单号自动跟踪，物流状态实时更新 |
| **支付系统** | 支持定金+尾款分期支付 |
| **地址管理** | 智能地址簿，快速选择收发地址 |
| **消息通知** | 订单状态变更实时推送 |
