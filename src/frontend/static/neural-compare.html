🧠 神经图谱视觉对比

原版实现 vs porweb 风格 - 看看区别在哪里

原版实现

我们最初的实现

特性

  • ✓50,000 粒子
  • ✗均匀橙-青渐变颜色
  • ✗简单球面分布
  • ✗无鼠标跟踪
  • ✗无脉冲效果
  • ✗无背景粒子

porweb 风格

基于 Datadryft/porweb 的实现

特性

  • ✓50,000 大脑粒子 + 5,000 背景粒子
  • ✓暗色为主，少量亮橙色高亮
  • ✓GLTF 模型表面采样（原版）
  • ✓鼠标跟踪旋转
  • ✓脉冲呼吸效果
  • ✓背景粒子缓慢旋转

🎨 颜色方案对比

// 原版 - 均匀渐变
const color = colorOrange.clone().lerp(colorCyan, Math.random());

// porweb - 暗色为主，少量高亮
if (randomVal > 0.999) {
  color = 0xffc266;  // 火花 0.1%
} else if (randomVal > 0.99) {
  color = 0xff8a00;  // 亮橙 1%
} else if (randomVal > 0.8) {
  color = 0x4a2000;  // 深橙 19%
} else {
  color = 0x00151a;  // 暗色 80%
}
