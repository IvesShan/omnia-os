## 🔧 协议实现

### 数据包格式

```
[0x55 0xAA] - 固定头部
[长度 2字节] - 数据长度
[版本 1字节] - 协议版本
[序列号 2字节] - 包序号
[源设备类型 1字节] - 发送方设备类型
[源设备编号 1字节] - 发送方设备编号
[目标设备类型 1字节] - 接收方设备类型
[目标设备编号 1字节] - 接收方设备编号
[命令ID 1字节] - 命令类型
[数据 N字节] - 数据内容
[CRC 2字节] - 校验码
```

### 设备类型

| 代码 | 设备 |
|------|------|
| 0x10 | PC (电脑端) |
| 0x0A | 飞控 |
| 0x03 | 相机 |
| 0x08 | 云台 |
| 0x12 | 感知模块 |
| 0x0B | 电池 |

### 命令ID

| 代码 | 命令 |
|------|------|
| 0x88 | 查询设备信息 |
| 0x0C | 查询设备状态 |
| 0xEA | 心跳包 |
| 0x07 | 进入升级模式 |

## 💡 使用提示

1. **关闭 DJI Assistant 2**
   - 避免设备被占用

2. **使用 sudo 权限**
   - USB Bulk 传输需要 root 权限

3. **检查设备连接**
   - 确保无人机已开机
   - 确保 USB 线缆连接正常

4. **查看日志**
   - 所有工具都有详细日志输出
   - 使用 `-v` 参数查看更多细节
