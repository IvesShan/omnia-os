## 3. 系统架构

### 3.1 核心模块

```
src/
├── api_server.py              # REST API 服务
├── main.py                    # 主程序入口
└── core/
    ├── cognition/             # 认知模块
    │   ├── recurrent_reasoning.py  # 循环推理
    │   ├── act_planner.py          # 任务规划
    │   ├── depth_adapter.py        # 深度适配
    │   └── chat_integration.py     # 对话集成
    ├── memory/                # 记忆模块
    │   ├── memory_manager.py       # 记忆管理
    │   ├── mla_compressor.py       # MLA 压缩
    │   └── neural_api.py           # 神经 API
    └── llm_client.py          # LLM 客户端
```

### 3.2 数据流

```
用户消息
    ↓
ACT 规划器 (复杂度评估)
    ↓
深度适配器 (确定推理深度)
    ↓
循环推理引擎 (多轮推理)
    ↓
记忆管理器 (检索/存储)
    ↓
MLA 压缩器 (压缩存储)
    ↓
响应生成
```
